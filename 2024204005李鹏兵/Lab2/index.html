守护密码、识破钓鱼、保护个人信息 —— 从今天的三件小事做起

🔐 密码安全 🎣 钓鱼识别 🛡️ 个人信息保护

1密码安全：一把钥匙配一把锁

弱密码是黑客最省力的入口。好密码的核心不是"复杂到记不住"，而是"每个账户都不一样，且足够长"。

应该做这样设置密码

  • 长度至少 12 位，越长越难破解
  • 使用"短语拼接法"：如 chai+he+2026!ShanBei 风格，好记又长
  • 重要账户（支付、邮箱、校园系统）开启双重验证（2FA）
  • 使用密码管理器，为每个账户生成独立随机密码

不要做这些常见错误

  • 所有网站共用同一个密码——一处泄露，全网失守
  • 使用生日、学号、手机号、姓名拼音做密码
  • 使用 123456、password、qwerty 等常见弱口令
  • 把密码写在便签上贴在电脑旁，或发到聊天群里

2识别钓鱼消息：三查一不点

钓鱼短信、假冒老师和"客服"是大学生受骗的重灾区。记住口诀：查发件人、查链接、查 urgency，不点不明链接。

钓鱼特征示例原文破绽

✅ 遇到可疑消息时的正确做法

  • 不点击短信、邮件、群文件里的不明链接
  • 通过官方 App 或官方电话核实，而不是回拨短信里的号码
  • "老师"在群里让你转账缴费？先当面或电话向本人确认
  • 凡是以"刷单返利""解冻账户""屏幕共享指导操作"开头的，直接拉黑举报

3个人信息保护：少晒、慎填、勤查

你的姓名 + 学号 + 手机号的组合，在黑产手里足以拼出精准的诈骗剧本。

📱 社交媒体

  • 不晒含学生证、火车票、准考证、登机牌的照片（含条码和学号）
  • 关闭"附近的人""可通过手机号找到我"等发现方式
  • 定位、宿舍门牌、课表截图都可能暴露行踪

📝 填表与注册

  • 扫码填问卷送礼品？先问：谁在收集、要我的什么信息、用来干什么
  • 非必要不提供身份证号；必须提供时确认对方资质
  • 注册不重要的网站可用"小号邮箱"，避免主邮箱被拖库

💻 设备与公共网络

  • 电脑手机设置锁屏密码，离开工位随手锁屏
  • 公共 Wi-Fi 不登录网银、支付类应用
  • 二手出清设备前彻底擦除数据，打印店打印后及时删除文件

4小测验：你能不能识破骗局？

点击选项即时判断，试试你的"安全直觉"。

收到短信："【教务处】您的奖学金已审批，请于今日 18 点前点击 t.cn/xxxxx 认领，逾期作废。"你应该？
✅ 正确答案：任何"限时认领 + 短链 + 假冒官方"三件套都是典型钓鱼特征。奖学金发放不需要你点外部链接，务必通过官方渠道核实。
同学借你的电脑"查个资料"，你最应该注意什么？
✅ 正确答案：设备可以借，账号不能"裸奔"。锁屏 / 登出是最简单的防护；事后查看账号登录记录，发现异常立即改密码。
