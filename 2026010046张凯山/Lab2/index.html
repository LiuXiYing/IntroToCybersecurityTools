Part 01

六大核心风险，从最容易踩的坑开始

每一条都对应着真实发生过的校园案例。请对照检查自己的习惯。

账号与密码安全

一个弱密码，等于把家门钥匙插在门上。

  • 同一密码不要到处复用，重要账号单独设置
  • 长度优先：12 位以上、大小写+数字+符号混排
  • 开启两步验证（2FA），如短信/验证器 App
  • 警惕"撞库"：某网站泄露后，黑客拿它去试你的其他账号

电信网络诈骗

骗子不靠技术，靠的是"拿捏你的情绪"。

  • 凡是要求转账 / 提供验证码的，先停三秒
  • 冒充公检法、客服、老师的，一律通过官方渠道回拨核实
  • 对方制造"紧急、限时、不能告诉别人"的紧张感 —— 这就是典型信号

个人信息保护

你的信息一旦散落，就会被"精准攻击"。

  • 身份证、学号、银行卡、家庭住址不要随意晒图
  • 快递单、车票、录取通知书拍照前先遮住关键信息
  • 非必要不填写真实信息；App 权限按需给
  • 社交媒体关闭"位置"和"陌生人可见"

公共 WiFi 与设备

免费 WiFi 可能是"钓鱼热点"，就等你登录。

  • 公共场所避免登录网银 / 输入密码
  • 关闭"自动连接 WiFi"，手动选择可信网络
  • 重要操作优先用手机流量或校园认证网络
  • 离开电脑记得锁屏（Win+L / Ctrl+Cmd+Q）

恶意软件与勒索病毒

一个"破解版安装包"，可能锁死你所有文件。

  • 不下载来路不明的"破解版 / 绿色版"软件
  • 不明邮件附件、陌生 U 盘不要随意打开
  • 系统和软件及时打补丁，安装正规杀毒软件
  • 重要资料定期备份（网盘 + 移动硬盘）

社交工程与钓鱼

骗局最锋利的一环，是假装成"你信任的人"。

  • 短信 / 邮件里的链接，先看域名是否与官方一致
  • 不扫来历不明的二维码（可能跳转钓鱼站）
  • 微信/QQ 收到"朋友"借钱，务必电话核实
  • 警惕"免费领皮肤/会员/资料"这类诱饵
Part 02

大学生最常遇到的 8 类骗局

骗子的剧本高度雷同。看懂套路，就不会踩进去。

1刷单返利 / 兼职诈骗

小单返现获取信任，随后诱导你垫付大额"任务"，再以各种理由拒绝返款。

凡是先刷单后返利的，100% 是骗局

2冒充客服退款

称"商品有问题可理赔"，引导你开启屏幕共享、提供验证码或贷款"清空额度"。

正规退货不会让你转账或贷款

3注销"校园贷"账户

谎称你的贷款记录影响征信，要求你贷款后转到"安全账户"注销。

征信不可"花钱消除"，直接挂断

4游戏账号 / 装备交易

低价收号、高价收购，用虚假交易平台收取"保证金""手续费"后消失。

脱离正规平台的交易都不安全

5冒充熟人 / 老师借钱

盗号后以同学、老师身份群发借钱，或伪造"领导"头像头像加你。

涉及转账，先打电话确认

6虚假招聘 / 培训贷

以"高薪兼职""先培训后上岗"为名，诱导签下高息贷款合同。

正规工作不会先让你交钱

7中奖 / 免费领奖

通知你"中奖了"，需先交"税费""邮费"才能领奖，或要求填写银行卡信息。

天下没有免费的"奖品"

8杀猪盘 / 网恋投资

伪造人设建立感情，再"带你投资理财"，先让你小赚，最后卷款消失。

网友带你投资，几乎必是骗局

    万一中招了？记住这 4 步

    被骗不是你的错，及时止损才是关键。慌乱和隐瞒只会让损失扩大。

    ① 立刻止损挂断电话 / 停止一切操作，不要再转账、不要再提供验证码。
    ② 保留证据截图保存聊天记录、转账凭证、对方账号，不要删除任何记录。
    ③ 快速报警拨打 110 或反诈专线 96110，越早报警越有可能冻结资金。
    ④ 修改密码如账号被盗，立即修改重要账号密码并开启两步验证，通知亲友防二次诈骗。

    Part 05

    别踩法律红线：有些"小事"其实很严重

    校园里最容易被忽视的，是"帮忙"与"玩一下"背后的法律风险。

    出借银行卡、电话卡、微信/支付宝账号

    即使你不知情，只要这些账户被用于诈骗、洗钱，就可能构成帮助信息网络犯罪活动罪（帮信罪），面临刑事处罚。切勿因小利出借。

    非法侵入他人系统、盗取账号

    破解同学 Wi-Fi、盗用账号、入侵学校系统，可能触犯《网络安全法》《刑法》中的非法侵入计算机信息系统罪、非法获取计算机信息系统数据罪。

    传播谣言、编造不实信息

    在社交平台编造、转发未经核实的突发事件信息，可能被追究行政乃至刑事责任。不造谣、不信谣、不传谣。

    翻墙访问境外非法网站

    使用违规工具访问境外非法网站属于违法行为；同时此类工具常夹带恶意程序，隐私与设备安全风险极高。
